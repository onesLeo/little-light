# Little Light — Godot (David & Goliath slice)

Biblical kids game prototype. Wonder-Walker guest/helper in a DOGWALK-style paper valley.

## Open once
1. `git clone https://github.com/onesLeo/little-light-godot.git`
2. Godot 4.3+ → Import this folder → F5
3. Later updates: `git pull` then reload in Godot

## Controls
- **WASD / arrows** — move (camera-relative)
- **E** — collect Wonder Items
- **Space** — dialogue / Steady Hands

## Notes
- Wonder-Walker is a guest, not David
- No violence shown
- Mic/voice features not wired (policy hold)
